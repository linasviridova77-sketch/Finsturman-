# ФинШтурман 1.0 — PWA + Supabase + Cloudflare Pages

Это мобильный финансовый помощник без подключения к банкам.

## Что умеет

- зарплата двумя частями;
- премия, отпускные, другое поступление;
- расходы: еда, машина/бензин, транспорт, связь, мелочи и свои категории;
- кредиты и кредитные карты;
- накопления/подушка;
- дневной ориентир до следующей выплаты;
- подсказка, куда направить поступившие деньги;
- проверка покупки;
- история решений;
- удаление записей;
- резервная копия JSON;
- синхронизация через Supabase;
- локальный кэш на iPhone/компьютере;
- PWA: можно добавить на экран «Домой».

## Безопасность

НЕ вводите:
- номера карт;
- CVV;
- банковские логины;
- SMS-коды;
- паспортные данные.

Используйте названия «Карта 1», «Кредитка», «Вклад».

`anon key` Supabase используется в браузере и не является сервисным секретом.
Безопасность строк в БД обеспечивается включённым RLS. Никогда не помещайте
`service_role` key в этот проект.

## Файлы

- `index.html` — оболочка приложения
- `app.js` — логика
- `styles.css` — мобильный дизайн
- `config.js` — Project URL + anon key Supabase
- `supabase-schema.sql` — таблица и RLS
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA
