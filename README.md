# ФинШтурман 0.2

Персональный финансовый помощник на Streamlit без подключения к банкам.

## Что умеет

- ручной учет карт, наличных и вкладов;
- ручной учет кредитов и кредитных карт;
- месячный бюджет;
- календарь обязательных платежей;
- распределение зарплаты и других поступлений;
- подсказка, какой долг сейчас приоритетнее;
- сценарии «куда направить свободные деньги»;
- прогноз даты выхода из долгов;
- режим «Хочу потратить» с оценкой последствий и паузой 72 часа;
- история финансовых решений;
- экспорт и импорт зашифрованной резервной копии.

> Не вводите номера банковских карт, CVV, логины, пароли, SMS-коды, паспортные данные или иные банковские реквизиты. Используйте условные названия: «Карта 1», «Кредит 1», «Вклад» и т. п.

## Как загрузить на GitHub через браузер

1. Создайте новый репозиторий, например `fin-shturman`.
2. Внутри репозитория нажмите **Add file → Upload files**.
3. Загрузите содержимое этой папки, сохранив папку `.streamlit` и файл `config.toml` внутри нее.
4. Нажмите **Commit changes**.

Важно: `app.py` и `requirements.txt` должны быть в корне репозитория.

## Как опубликовать в Streamlit Community Cloud

1. Откройте Streamlit Community Cloud и войдите через GitHub.
2. Нажмите **Create app / Deploy an app**.
3. Выберите репозиторий `fin-shturman`.
4. Branch: `main`.
5. Main file path: `app.py`.
6. При первом развертывании можно оставить стандартную поддерживаемую версию Python.
7. Нажмите **Deploy**.

После публикации появится адрес вида:

```text
https://ваше-имя.streamlit.app
```

## iPhone

Откройте опубликованную ссылку в Safari. При желании используйте **Поделиться → На экран «Домой»**, чтобы запускать помощника с домашнего экрана.

## Локальный запуск на компьютере

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Резервные копии

Streamlit Community Cloud не следует использовать как единственное долговременное хранилище персональных финансовых данных. Регулярно экспортируйте зашифрованную резервную копию из приложения и храните ее у себя.
